# Formula 1 Driver Gallery

A simple, pure-HTML web project designed to display a gallery of Formula 1 drivers, focusing on semantic HTML5 best practices for rendering images and captions.

## Project Goals

The main objective of this project is to practice semantic HTML5 structuring without using CSS styles or JavaScript, focusing strictly on the proper implementation and association of images with their respective captions.

## HTML Tags Used

The driver gallery is built using three essential semantic HTML tags:

- `<figure>` : The container tag used to group media content alongside its explanatory caption.
- `<img>` : The element responsible for loading and displaying the driver's image (`src`, `alt`).
- `<figcaption>` : The element that provides a description or caption for the image inside the `<figure>`.

## Code Snippet

Below is an exemple of the core HTML bock used in the gallery.

```HTML
<figure>
    <img src="./images/p1.jpeg" alt="Lewis Hamilton's photo" width="200">
    <figcaption>Lewis Hamilton</figcaption>
</figure>
```
